# 需求理解 · OMD UI 增强版 0.3.0

本包为 `gulagala001/omd-prompt-optimizer` 的独立发行版，使用 WestFox-AwA / 啃轮胎的西狐的 dsh-prompt-optimizer 0.7.4 解释与校验引擎（BSD-3-Clause）。不是上游官方发行版，不与 OMD 自带的草稿“提示词优化”混为一谈。

本版适配 DSH `0.2.0-rc.2` 和 `0.2.1-alpha.1`；旧 DSH `0.1.7-rc.2` 环境继续使用本组件 `0.1.0`。

## 使用

手动安装后，在“设置 → 需求理解”开启。默认关闭，不拦截发送，不注入上下文，不注册任何工作模型工具。开启后，输入框出现一个紧凑的“需求理解”入口；发送前先生成解释，默认由你审查，再采用并发送原话。

可以选择轻度/标准/重度，审查/自动，跟随会话或指定解释模型，最近 0–10 回合或可读历史，以及只读项目文件。结果可编辑、停止或跳过；修改草稿、附件或设置后，旧结果不会自动发送。关闭时取消未完成请求并卸载发送/上下文钩子。配置按 DSH_HOME/profile 隔离存放在 `omd-intent-assistant.json`，不修改上游或 OMD 的配置文件。

不提供附带 Bash，不改变原有工具、记忆、压缩或前置推理。原话与附件由宿主原生发送；解释作为紧随原话的独立随行消息，只给对应输入投递一次，明确标注仅辅助理解对应的用户消息。随行解释按宿主的正常机制保留在会话历史；组件不会为后续输入重复挂接上一轮解释，历史保留不表示它成为新一轮用户要求。

## 数据与限制

开启时使用你配置的模型服务，因此原话、选中的历史和允许读取的文件会发送给该服务；无作者遥测。最近回合历史预算 12,000 字符，可读历史 60,000 字符，超出会标明截断，并非无限完整上下文。模型调用与工具核验存在额外延迟和费用，真实 token 缺值显示“—”。

关闭只停止后续行为，不能撤销过去发出的内容、费用或回答。管理 API、安装文件与设置入口保留；它不是进程级零占用。不同浏览器以服务端禁用为准，界面在下次交互或刷新同步。不要同时启用原版上游的发送拦截器。可与 OMD 原有手动提示词优化并存；两个自动处理器同时开启可能重复调用，修改后的输入不会套用旧解释。

## 验证范围

本包的兼容声明明确列出 DSH `0.2.0-rc.2` 和 `0.2.1-alpha.1`。离线单元测试覆盖默认关闭、启停、取消与晚到、会话/消息隔离、原话和附件保留、命令直通、发送来源参数保留、输入修改保护、包装器共存和上游解释校验管线。

原生兼容测试分别使用 macOS 上的原版 DSH `0.2.0-rc.2`、`0.2.1-alpha.1`，在独立 profile 安装实际 tarball，不使用版本豁免或源码链接。测试覆盖原生客户端加载、默认关闭、审查和自动发送、原话及图片字节保留、取消、启停、进程重启与卸载。另有 OMD 集成测试覆盖本地模拟模型请求、只读文件工具、明暗主题与窄屏布局。模拟模型测试验证接线与状态，不代表真实模型能力提升。Windows/Linux 原生桌面和真实供应商效果不由此推断。

运行原生测试时，显式设置 `OMD_NATIVE_MATRIX=1`、候选包 `OMD_INTENT_PACKAGE`、旧版包 `OMD_INTENT_BASELINE_PACKAGE`，以及两个宿主的 CLI 绝对入口 `OMD_NATIVE_RC_CLI`、`OMD_NATIVE_ALPHA_CLI`。提供 `OMD_NATIVE_PLAYWRIGHT` 的模块绝对入口；也可用显式 `OMD_CHECKOUT` 从该工作区解析 Alpha CLI 与 Playwright。可用 `OMD_NATIVE_CHROMIUM` 指定 Chromium/CFT 可执行文件。然后运行 `node --test omd/test/host-compat.test.mjs`；未启用时会明确跳过，缺少必需配置时会报错。
