# 需求理解 · OMD UI 增强版 0.1.0

独立 fork 发行版，基于 WestFox-AwA / 啃轮胎的西狐的 dsh-prompt-optimizer 0.7.4。保留上游解释、校验、策略与编译引擎，重做界面和 DSH/OMD 适配。

## 使用

从 OMD 推荐插件手动安装，或将附件 `omd-prompt-optimizer-0.1.0.tgz` 安装到指定 DSH profile。**不会随 OMD 自动安装；手动安装后也默认关闭。** 启用入口为“设置 → 需求理解”，默认先审查再发送。

- 紧凑输入入口、清晰的需求卡片、可编辑随行内容、实际用量、解释进度和停止/跳过。
- 跟随 OMD 主题与配色，适配浅深色和窄屏；保留模型、档位、历史范围和只读查证设置。
- 使用原生输入组件与发送生命周期，原话和附件不改写，不给工作模型新增工具或 Bash。
- 关闭会取消未完成调用，拒收晚到结果，移除发送钩子与输入界面；不改 OMD 记忆、压缩或原有提示词优化。

## 验证

- 增强版单元测试 **14/14**：默认关闭、审查/自动、取消、晚到、会话及队列隔离、原话与附件保留、命令直通、卸载与其他包装器共存。
- 上游解释器 **20/20**、管线 **23/23**、只读工具 **10/10**，相关上游源文件未修改。
- macOS 的真实 DSH Web + OMD 隔离 profile：实际 tgz 安装、默认关闭、审查编辑发送、原话和工具清单对照、真实只读工具轮次、自动发送、浅深色/390px 窄屏、停止及关闭时取消、刷新持久化、从推荐页面卸载，全部通过且无浏览器错误。
- 使用本地模拟模型服务验证接线，未使用这些测试证明真实模型能力提升、节省 token 或全部原生桌面平台兼容。

适配 DSH **0.1.7-rc.2**、OMD **0.1.7-rc.2.15**。原始上游来源见包内 `UPSTREAM.json`，许可为 BSD-3-Clause。

已发出的随行消息保留在历史；“关闭”停止后续处理，不撤销已有回答或费用。开启时选定材料会发给用户配置的模型服务，无作者遥测。
